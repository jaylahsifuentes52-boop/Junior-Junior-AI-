JUNIOR AI - NEON STYLE

This ZIP contains the updated style.css stylesheet.

HOW TO USE:
1. Extract the ZIP file.
2. Copy style.css into the same folder as your index.html.
3. Replace the old style.css file.
4. Make sure index.html has this inside its <head> section:
   <link rel="stylesheet" href="style.css">

The HTML needs matching class names such as .navbar, .hero, .features-grid,
.panel, .chat-box, and .code-editor for the styles to appear.
